# UPP Projekt — JGL: Zapošljavanje IT djelatnika (BPMN + DMN + Camunda 8)

Ovaj repozitorij sadrži analizu i modeliranje AS-IS i TO-BE procesa zapošljavanja IT djelatnika u JGL-u,
uz DMN odluke i Camunda 8 forme integrirane u TO-BE model.

## Modeli
### BPMN
- AS-IS: `it-hire-as-is.bpmn`
- TO-BE: `it-hire-to-be.bpmn`

### DMN
- `models/dmn/it-hire-decisions-fixed.dmn`

### Forme (Camunda 8)
- `form-unos-zahtjeva.form`
- `form-unos-ocjena-intervjua.form`
- `form-slanje-ponude.form`
- `form-potpis-ugovora.form`
- `form-nabava-rezervacija-opreme.form`
- `form-potvrda-dostupnosti-opreme.form`
